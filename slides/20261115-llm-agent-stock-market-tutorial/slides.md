# 逐頁內容

## 第 1 頁｜封面
**核心訊息：** 股票研究裡的 Agent 不只會說明，也能接工具或模擬環境。  
**要點：** 從工具問答到多代理人市場模擬；教材根據 Wiki 五篇來源。  
**對照：** Notes 一分鐘版本。

## 第 2 頁｜Agent 是什麼？
**核心訊息：** Agent 是模型在任務中規劃、行動、讀取結果並調整下一步的系統。  
**要點：** LLM 理解與決策；工具提供資料或執行；環境回傳觀察結果。  
**對照：** Notes「從聊天模型到 Agent」；Wiki Agent 概念頁。

## 第 3 頁｜Agent 工作迴圈
**核心訊息：** 任務會經過可檢查的迴圈，不是一口氣猜答案。  
**要點：** 問題 → 規劃 → 行動 → 觀察 → 檢查 → 再行動或回答；工具錯誤時回到規劃。  
**對照：** Notes「從聊天模型到 Agent」；ReAct、PAL。

## 第 4 頁｜兩種股票研究 Agent
**核心訊息：** FinAgent 是技術分析輔助；StockAgent 是觀察代理人市場行為的模擬框架。  
**要點：** 查詢與計算 vs 多人互動模擬；任務不同，不可視為同一準確率。  
**對照：** Notes「兩種股票研究 Agent」。

## 第 5 頁｜FinAgent 怎麼回答？
**核心訊息：** 語言理解、行情工具與數值計算彼此分工。  
**要點：** 提問 → ReAct 選工具 → 取數 → Node.js 執行指標計算 → 模型解讀；小型受控測試中實際執行優於模型估值。  
**對照：** Notes「兩種股票研究 Agent」；FinAgent 來源頁、PAL 頁。

## 第 6 頁｜StockAgent 如何模擬市場？
**核心訊息：** 多個投資代理人互動，撮合系統更新價格，形成下一輪。  
**要點：** 不同人格；讀取行情／條件／BBS；提交買賣；order book 撮合；市場狀態回饋代理人。  
**對照：** Notes「兩種股票研究 Agent」與「教學例子」。

## 第 7 頁｜模擬研究能回答什麼？
**核心訊息：** 可比較設定下的代理人行為，不能直接證明真實市場獲利。  
**要點：** 比較兩種 LLM 模擬交易行為；外部條件消融改變部分結果；股票匿名且情境由研究者設定。  
**對照：** Notes「兩種股票研究 Agent」；StockAgent 來源頁。

## 第 8 頁｜可靠度有不同層次
**核心訊息：** 工具、計算、解釋、模擬和投資績效不是同一件事。  
**要點：** 資料新鮮嗎？計算可重現嗎？解釋有根據嗎？模擬適合嗎？有無時間外市場測試與成本風險？  
**對照：** Notes「如何讀可靠度」。

## 第 9 頁｜新手讀論文的三個檢查點
**核心訊息：** 先辨認任務、環境與證據界線。  
**要點：** 系統做問答、價格迴歸還是模擬？資料從哪裡來？結論有否超出樣本與模擬條件？  
**對照：** Notes「如何讀可靠度」；跨來源 Wiki 綜述。

## 第 10 頁｜帶走的結論
**核心訊息：** Agent 能力來自模型、資料、工具和環境；真實投資可靠度仍需獨立驗證。  
**要點：** Agent → ReAct／PAL → FinAgent → StockAgent → 五篇來源比較；候選閱讀尚未納入 Wiki。  
**對照：** Notes 結論與後續閱讀。
