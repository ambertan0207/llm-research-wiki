# 逐頁內容

## 第 1 頁｜封面

**核心訊息：** 這是一個把 LLM、即時資料工具和程式執行串在一起的股票技術分析輔助原型。

**頁面要點：**
- 以自然語言問技術分析問題
- 研究案例：FinAgent
- 本簡報回答：是什麼、如何運作、可靠度有多高？

**講者備註：** 今天聚焦系統能力與證據界線，不把技術指標分析等同於交易績效。

**來源對照：** Notes「研究問題」「簡答」；Wiki 來源頁摘要。

## 第 2 頁｜一句話說明：LLM Agent 是什麼？

**核心訊息：** Agent 不只生成文字，而是在工具與環境回饋中規劃、執行並整理結果。

**頁面要點：**
- LLM：理解問題、安排步驟、解讀結果
- 工具：取得模型自身沒有的即時資料
- 執行環境：處理需要精確的數值運算
- FinAgent 定位為決策輔助原型，不是自動交易者

**講者備註：** 把 Agent 看成一個工作流程，比只看模型名稱更能理解系統能力。

**來源對照：** Notes「這種系統是什麼」；Wiki「大型語言模型代理人」。

## 第 3 頁｜FinAgent 怎麼運作？

**核心訊息：** 一個問題會經過四個環節：理解與規劃、工具取數、程式實際計算、自然語言解讀。

**頁面要點：**
1. GPT-4o 理解使用者的股價、指標或 K 線問題並規劃所需資訊。
2. ReAct 迴圈按任務呼叫行情／指標工具。
3. Node.js 執行具體數值計算。
4. GPT-4o 依實際數值整理分析說明。

Reflexion/RAG 記憶與 PromptEvolver 改進規則提供額外的修復／召回路徑。

**講者備註：** 即時資料和確定性計算解決不同問題；記憶模組是另外一層，需獨立驗證效果。

**來源對照：** Notes「如何運作」；Wiki 來源頁「系統設計」。

## 第 4 頁｜ReAct：邊推理，邊使用工具

**核心訊息：** 工具讓模型取得即時脈絡；它不是靠訓練記憶猜今日行情。

**頁面要點：**
- Agent 依問題選取行情或指標工具，讀取結果後再決定回答。
- 工具增強對照：原生 LLM 0/6 得分；工具 Agent 6/6 滿分。
- 6 題中平均呼叫 1.67 次工具、2.67 輪推理。
- 結果只代表論文設定的 6 題。

**講者備註：** 這個測試驗證的是特定問答能否取得／整合資料，不是股票預測能力。

**來源對照：** Notes「如何運作」「可靠度：目前測到了什麼」；Wiki ReAct 頁；來源論文印刷頁 22–24、34–35。

## 第 5 頁｜PAL：生成程式碼，還得真的執行

**核心訊息：** 在受控指標題中，模型自行估值很不穩；程式執行組表現較好。

**頁面要點：**
- PAL Full（後端實際計算）：6/6 滿分。
- PAL No-Execution（模型依程式邏輯自行估值）：5/6 失敗，平均 0.17/3。
- 失敗中有 4 題連判斷方向也錯。
- LLM 負責語意分解與解釋；程式執行具體計算。

**講者備註：** 這是簡報中支持度最強的可靠度訊號，但分母仍是 6 題，而且程式執行正確也不代表資料源或交易判斷必然正確。

**來源對照：** Notes「可靠度：目前測到了什麼」；Wiki PAL 頁；來源論文印刷頁 31–40。

## 第 6 頁｜記憶與自我修正：有設計，不等於已證實增益

**核心訊息：** Reflexion/RAG 旨在修復失敗與累積經驗；本論文測試沒有量出額外效果。

**頁面要點：**
- Reflexion：單次任務失敗後診斷並重試。
- RAG：把修復經驗存下來，供相似任務召回。
- 測試三組各 6 筆，全部 6/6 首輪成功；沒有失敗可修復或累積。
- 因基線已全過，不能據此判定記憶模組提高或沒有提高真實效能。

**講者備註：** 這是評估設計的天花板問題，不應把機制描述當成實證結論。

**來源對照：** Notes「可靠度：目前測到了什麼」「仍未確立的部分」；Wiki Agent 記憶頁；來源論文印刷頁 28–30、37–39。

## 第 7 頁｜可靠度成績單：要看任務，不看單一百分比

**核心訊息：** 成績依測試面向而異，不能合併成通用的「Agent 準確率」。

**頁面要點：**
- 工具增強：6/6 滿分（即時資料問答）。
- 程式實際執行：6/6 滿分（受控指標題）。
- 不執行、由模型估算：5/6 失敗。
- Reflexion/RAG：所有組別 6/6 首輪通過，增量效果未測出。

**講者備註：** 數字看似精確，但每組樣本很小，適合作為概念驗證訊號，不能外推成穩定市場可靠度。

**來源對照：** Notes「可靠度判斷與限制」；Wiki FinAgent 來源頁。

## 第 8 頁｜目前能說多可靠？

**核心訊息：** 對特定數值流程有初步受控證據；對投資結果與普遍情境仍未知。

**頁面要點：**
- 有支持：外部工具解決即時資料取得；程式執行降低模型自行估值的錯誤。
- 尚未確立：跨模型／跨股票／跨時間的穩定性、記憶增益、使用者信任。
- 未測得：回測報酬、風險調整績效、基本面與新聞整合。
- 結論：技術原型可行，不等於已證明投資可靠。

**講者備註：** 強調「計算可靠度」和「投資決策可靠度」是兩回事。

**來源對照：** Notes「可靠度判斷與限制」「結論」；Wiki FinAgent 來源頁第六章。
