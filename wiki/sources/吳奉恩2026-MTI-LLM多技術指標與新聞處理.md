# 結合 LLM 驅動之新聞處理與多元技術指標於股票趨勢預測

## 研究問題與方法

研究提出 MTI-LLM：以提示詞引導 Qwen2.5:3B 過濾與個股預測相關的中文財經新聞，並將保留新聞映射為上漲（+1）、持平（0）、下跌（−1），每日彙整平均、最大、最小情緒分數。量化特徵包括價量、技術指標、EPS 與日曆特徵；以連續七個交易日作為輸入窗口，預測下一日收盤價，使用 XGBoost 與 Temporal Fusion Transformer（TFT），以 MAE、RMSE、R² 等評估。研究期間為 2024 年，新聞透過 GNews API 等方式蒐集，股價來自證交所。

論文摘要稱主要實證標的為台達電、中華電信、日月光；方法章另列台達電、鴻海、中華電信、日月光四檔。此處存在摘要與方法章不一致，故標記為待核對，不將標的數量當作已確定資訊。

## 主要發現

- 作者報告 MTI-LLM 在多數比較中的誤差指標較低、R² 較高，整體優於基礎股價方法及文獻方法；TFT 對台達電與日月光的比較改善較明顯。
- 研究將 LLM 同時用於新聞相關性篩選與情緒分類；方法章指出新聞情緒特徵由 Qwen2.5:3B 產生，而不是使用 FinBERT 作為情緒模型。
- 作者指出資料蒐集及 LLM 逐篇處理成本高，受時間與算力限制，研究資料規模有所限縮。

## 限制與注意事項

- 原文把結果描述為「預測準確度」改善，但使用的是股價迴歸誤差與 R²；不應與漲跌方向分類準確率混為一談。
- 可見章節未呈現多年度／跨市場驗證或交易成本後回測；模型預測誤差改善不能直接證明可獲利。
- 四檔或三檔標的的內部不一致需查閱原文表格與附錄後再定稿。
- 與 [[孫佳鴻2026-LLM新聞篩選與台股預測]] 同為 2026 年、同一指導教授並採用 MTI-LLM 名稱，但兩者的情緒模型、股票集合與實驗設計不同。不得視為同一研究或將其結果直接合併；應另查作者、版本與研究承接關係。

## 與 Wiki 的關聯

此研究將 LLM 用作金融文本過濾和情緒特徵生成，再與結構化市場特徵共同輸入預測模型；可與 [[張耿瑜2025-LLM新聞情緒與台積電預測]] 比較本地 LLM 情緒分數與滑動窗口融合設計，並與 [[李旻珊2026-LLM-Agent股票技術分析]] 比較「Agent 執行工具」與「LLM 作為特徵工程模組」兩種系統定位。
