## 綜合觀察

1. **LLM 用途不同。** FinAgent 把 LLM 放在 Agent 推理及工具協調層；張耿瑜與吳奉恩用 LLM 產生新聞情緒或篩選特徵；孫佳鴻則以先行研究的 LLM 關鍵字篩選作基準，再研究技術、籌碼與市場情緒特徵。不能把「含 LLM」視為同一方法。
2. **預測目標需先對齊。** 張耿瑜、吳奉恩、孫佳鴻主要呈現隔日收盤價迴歸；FinAgent 來源頁聚焦工具使用與指標問答。名稱含「方向／趨勢」不代表實驗就是漲跌分類。
3. **特徵有增益的證據取決於比較設計。** 孫佳鴻以受控特徵組合較能分離特徵家族的邊際影響，但其驗證切分有偏誤風險。張耿瑜報告整體模型結果，不能據此把效果歸因於 LLM 情緒單一特徵。其他論文也不能外推至相同市場和年份。
4. **誤差改善不是投資績效。** 四篇來源均不足以共同支持「可穩定獲利」的結論。仍需嚴格時間外推、交易成本／滑價、風險調整報酬與多市場測試。
5. **吳奉恩與孫佳鴻兩篇待做版本／承接核查。** 兩篇均為 2026 年、同一指導教授且使用 MTI-LLM 名稱，但方法差異明確；吳奉恩論文摘要與方法章的股票數也不一致。應維持為不同來源，日後核對原始表格、資料集與研究承接關係。

## 研究缺口

- 需要以相同股票、日期、新聞語料與嚴格時間序列切分，對照原始價量、傳統情緒模型、LLM 情緒、LLM 新聞篩選及 Agent 工具執行。
- 需逐項報告新聞時間戳與市場資料可得時間，避免未來新聞或盤後資料洩漏至預測特徵。
- 需要把分類指標、價格誤差、交易策略績效與使用者決策品質分開衡量。
- 建議取得何銘哲（2025）前置論文，並核對吳奉恩論文股票數、實驗表格和版本來源。
