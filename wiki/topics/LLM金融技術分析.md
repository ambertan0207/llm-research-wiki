# LLM 金融技術分析

## 範圍

此頁追蹤 LLM／Agent 如何取得金融市場資料、計算技術指標並解釋訊號。技術分析結果與投資報酬、交易策略有效性是不同研究問題，不能由指標計算正確直接推出投資獲利。

## 來源脈絡

目前納入四篇台灣碩士論文，研究問題涵蓋 Agent 技術分析輔助、LLM 新聞情緒特徵、新聞過濾與多特徵股價迴歸。設計、期間與指標不同，不應將數值直接比較為方法排名。跨來源比較見 [[LLM新聞技術指標股價預測-四篇來源比較]]。

### Agent 技術分析輔助

[[李旻珊2026-LLM-Agent股票技術分析]] 建置以 GPT-4o 為推理核心的股票技術面輔助系統，整合即時行情、RSI/MACD/KD/SMA 等指標、ReAct 工具迴圈與 PAL 式後端程式執行。四項小型概念驗證中，工具組在 6 題全數滿分；PAL Full 在 6 題全數滿分，No-Execution 5/6 失敗；CoT/Few-Shot 的各組一致率 100%；Reflexion/RAG 比較因所有組別首輪 100% 通過而無法顯示額外效果。

作者將系統定位為決策輔助，非投資決策替代品。研究未評估回測報酬，也未涵蓋基本面、新聞與總體經濟；沒有正式使用者試驗。

### 新聞情緒與收盤價預測

[[張耿瑜2025-LLM新聞情緒與台積電預測]] 以本地 Gemma／DeepSeek 處理鉅亨網新聞，再結合技術特徵，以 MLR 預測台積電隔日收盤價。論文報告測試集 RMSE 約 18.37 元、R² 約 0.5949。其題名使用「方向預測」，但實際目標是收盤價迴歸；且未見足以將整體結果歸因於情緒特徵的消融對照。

### 多特徵與新聞處理

[[吳奉恩2026-MTI-LLM多技術指標與新聞處理]] 以 Qwen2.5:3B 篩選新聞並產生情緒特徵，結合技術指標後用 XGBoost／TFT 預測隔日收盤價。摘要與方法章列出的股票數量有差異，來源頁保留待核狀態。

[[孫佳鴻2026-LLM新聞篩選與台股預測]] 在 FinBERT 情緒與價量基準上，以 16 種特徵組合和多種子比較技術、籌碼及市場情緒的邊際貢獻。作者報告完整特徵組合改善誤差指標，但承認隨機切分與全樣本正規化有前視偏誤風險，且未證明實際投資獲利。

這些來源支持的是不同任務下的可行性或樣本內／測試集預測結果，並未形成「LLM 能可靠預測並獲利」的共同證據。

## 待追問題

- 不同市場資料供應商的延遲、缺漏與公司行動調整，如何影響技術指標？
- 對多模型／多資料源的 Agent 評估，如何避免同一模型同時生成與打分？
- 如何將數值正確性、解釋品質、使用者信任與交易績效分開量測？
- 對投資輔助介面，何種不確定性呈現能減少過度信任？
- 若整合回測，如何避免前視偏誤、資料洩漏與過度擬合？
