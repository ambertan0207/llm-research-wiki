# HTML 簡報區

每個研究題目使用 `html/<專案代碼>/index.html`，並以對應的 `slides/<專案代碼>/slides.md` 為唯一內容來源。

## 已確認的視覺方向

採用「奶油手帳＋薰衣草剪貼簿」：奶油白 `#F7F1E5` 作底色，搭配霧紫 `#C8BEDA`、灰藍 `#B9CAD5`、淡粉 `#E6C5CC`、蜜桃粉 `#E9B9AE`、鼠尾草綠 `#B9C6AE`。以紙膠帶、索引卡、手繪重點與柔和圓角作少量裝飾；標題帶手寫感，正文保持清晰易讀、留白與足夠對比。

正式簡報採用頁面上一頁／下一頁控制、方向鍵操作與列印樣式，除非使用者另有要求。Notes 或逐頁稿更新後，檢查 HTML 是否需同步，並記錄依據的逐頁稿、更新日期及狀態。優先支援離線瀏覽。
