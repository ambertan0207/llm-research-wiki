Agent 是什麼？

02　工作迴圈

Agent 如何一步步工作？

每次行動都會帶來新的觀察；需要時可以回到前一步修正。

①問題使用者提出目標
②規劃判斷要查什麼、做什麼
③行動呼叫工具或程式
④觀察讀取工具回傳結果
⑤檢查／回答重試或整理結論
這就是迴圈：結果不合預期時，Agent 回到規劃或行動步驟。

03　兩種研究問題

股票研究裡的兩種 Agent

名字都叫 Agent，工作目標可以很不一樣。

面向使用者

FinAgent

查行情、算技術指標、把數值整理成分析說明。

工具取數程式計算

面向研究者

StockAgent

讓多個代理人在設定的市場裡互動交易，觀察行為差異。

多代理人市場模擬

一個在回答分析問題；另一個在模擬代理人行為。不能用同一種「準確率」比較。

05　案例二：StockAgent

如何模擬一群投資者？

每位代理人讀取條件、作出交易，再由市場規則撮合。

代理人

設定不同人格，閱讀市場資訊與其他人的留言。

撮合市場

提交買賣訂單，撮合成交並更新價格。

下一輪

新價格與訊息回到代理人，形成後續決策。

06　證據的範圍

模擬研究能回答什麼？

可以看設定改變時，代理人的反應如何不同。

可以觀察

模擬行為

特定模型和規則下，交易頻率、交易量或群體行為的差異。

不能直接推論

真實獲利

人工市場裡的盈虧不等於真實市場能重現的績效。

StockAgent 用匿名股票和研究者設定的環境；它研究模擬，不是已證明的實盤預測器。

07　可靠度分層

先問：哪一種可靠？

可靠度不是一個可以套在所有工作的單一分數。

取數

資料新鮮、完整、時間對齊嗎？

計算

數字能由程式重現嗎？

投資結果

有未來市場測試、成本和風險嗎？

前兩關表現良好，不會自動證明最後一關有效。
