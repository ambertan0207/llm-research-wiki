# 研究問題

讓沒有金融 AI 背景的讀者理解股票研究裡的 LLM Agent 如何運作，以及如何分辨「能計算／能模擬」和「能在真實市場可靠獲利」。

## 一分鐘版本

LLM Agent 以語言模型處理任務，按需要使用工具並讀取結果。股票研究至少有兩種用法：FinAgent 用工具取得行情並以程式執行技術指標計算；StockAgent 讓多個模型代理人依模擬規則互動交易。前者做小型工具與計算概念驗證，後者觀察指定模擬條件下的交易行為；兩類結果都不能單獨證明真實市場可穩定獲利。

## 從聊天模型到 Agent

Agent 會理解目標、選工具、取得觀察結果，再決定下一步。流程可寫成：**問題 → 規劃 → 工具／環境行動 → 觀察結果 → 檢查與再決定 → 回答**。[大型語言模型代理人](../../wiki/concepts/大型語言模型代理人.md) 說明規劃與工具；[ReAct](../../wiki/concepts/ReAct推理與行動.md) 說明推理與行動交替；[PAL](../../wiki/concepts/PAL程式輔助與外部執行.md) 說明精確數值可交由外部程式執行。

## 兩種股票研究 Agent

| 面向 | FinAgent 技術分析輔助 | StockAgent 多代理人模擬 |
|---|---|---|
| 研究問題 | 能否查詢行情、計算指標並解釋 | 不同 LLM 代理人在設定市場中如何交易 |
| 系統 | 面向使用者的分析 Agent | 多個代理人與模擬市場 |
| 流程 | 提問 → 工具取數 → 程式計算 → 解讀 | 市場條件 → 代理人決策 → 訂單撮合 → 價格更新 |
| 證據界線 | 小樣本概念驗證，未證明實際績效 | 模擬行為不等於真實市場預測 |
| Wiki 頁 | [FinAgent](../../wiki/sources/李旻珊2026-LLM-Agent股票技術分析.md) | [StockAgent](../../wiki/sources/Zhang2026-StockAgent多代理人股票市場模擬.md) |

FinAgent 在特定六題工具與實際程式執行測試中取得滿分；模型不執行程式而自行估值的 PAL 組六題中有五題失敗。記憶增益未辨識，樣本小且無交易績效測試。詳見 [FinAgent Notes](../20261115-finagent-agent-what-how-reliable/notes.md)。

StockAgent 使用 GPT-3.5-Turbo 與 Gemini-Pro 驅動模擬代理人，報告兩組在成交量、交易頻率、價格路徑與群體行為上有差異；移除部分條件也改變特定模擬結果。這支持「特定設定可比較代理人行為」，不支持模型已能預測真實股價或模擬盈虧可在市場重現。

## 如何讀可靠度

1. **資料取得**：行情是否即時、完整、時間對齊？
2. **計算**：指標由可重現程式計算，還是模型自行估值？
3. **解釋**：輸出是否對應資料與問題？
4. **模擬**：環境規則和代理人假設是否適合研究問題？
5. **真實績效**：是否有無洩漏的時間外測試、交易成本及風險調整結果？

前幾項不自動回答最後一項。計算正確是工程能力；模擬行為可比較是方法能力；投資策略是否穩定是另一個實證問題。

## 教學例子

把 StockAgent 想成可設定規則的桌上市場：不同風格代理人閱讀價格、財報、利率或留言並提交交易；撮合模組更新成交和價格，再進入下一輪。研究者可移除一項條件觀察變化。這是系統設計示意，不是真實交易建議。

## 結論

Agent 能接工具取資料、以程式執行提高數值可驗證性，多代理人模擬讓研究者觀察設定條件下的互動。判定真實市場可靠度仍需更嚴格且可外推的市場驗證。本結論是根據 Wiki 兩類研究作出的有限綜合，不代表領域共識。
