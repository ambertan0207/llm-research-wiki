日期：2026-11-15。實際完成一次 Wiki → Notes → 逐頁稿 → HTML 製作與檢查。資料庫共有五篇研究來源。

## Loop / Graph 設計

取得來源／raw → 讀 index 和相關 Wiki → 更新來源及主題頁 → 確認教學問題 → 寫 Notes（只用 Wiki 證據）→ 檢查主張與證據界線 → 編排逐頁稿 → 逐頁對照 Wiki → 產生 HTML → 檢查頁數、導覽、連結與圖片 → 記錄及更新網站。

Notes 檢查若發現缺口或歧義，回到來源／Wiki 查核；逐頁稿對照失敗，回 Notes 修正；HTML 有內容或導覽問題，回逐頁稿重建。新增來源也會重跑相關頁面的交叉引用檢查。
